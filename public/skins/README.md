# 自定义壁纸槽说明

把图片放进这个文件夹（public/skins/），命名为槽位编号即可，无需改任何代码：

| 皮肤槽   | 桌面端文件名（任选一个）            | 手机端专用（可选）                    |
| -------- | ----------------------------------- | ------------------------------------- |
| 壁纸·壹  | `1.jpg` / `1.png` / `1.webp` / `1.svg` | `1-m.jpg` / `1-m.png` / …          |
| 壁纸·贰  | `2.jpg` / `2.png` / `2.webp` / `2.svg` | `2-m.jpg` / `2-m.png` / …          |
| 壁纸·叁  | `3.jpg` / `3.png` / `3.webp` / `3.svg` | `3-m.jpg` / `3-m.png` / …          |

- 探测顺序按设备自适应：手机/窄屏先找 `-m` 后缀的竖构图，找不到退回普通版；桌面端反之，只放一张也能双端用。
- 扩展名匹配顺序：jpg → jpeg → png → webp → svg（用户放的图盖过本目录自带的示例 `1.svg`）。
- 放好后刷新页面，到首页头部点「皮肤」按钮即可切换。
- 建议：桌面端 ≥ 1600×900 横构图；手机端 `-m` 版用 ≥ 720×1280 竖构图。
- 图片以 cover 方式铺满并加白色柔光罩（竖图定位偏上 1/3，保住人像脸部），文字可读性不受影响。
- 注意版权健康度：自己拍的、官方壁纸、可商用素材都行。
