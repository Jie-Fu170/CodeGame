# 自定义壁纸槽说明

把图片放进这个文件夹（public/skins/），命名为槽位编号即可，无需改任何代码：

| 皮肤槽   | 可用文件名（任选一个）                                        |
| -------- | ------------------------------------------------------------- |
| 壁纸·壹  | `1.jpg` / `1.jpeg` / `1.png` / `1.webp` / `1.svg`             |
| 壁纸·贰  | `2.jpg` / `2.jpeg` / `2.png` / `2.webp` / `2.svg`             |
| 壁纸·叁  | `3.jpg` / `3.jpeg` / `3.png` / `3.webp` / `3.svg`             |

- 探测顺序：jpg → jpeg → png → webp → svg，用户放的图会盖过本目录自带的示例 `1.svg`。
- 放好后到首页头部点「皮肤」按钮（Acts 显示当前皮肤）即可切换。
- 建议尺寸 ≥ 1600×900，横向构图；图片会以 cover 方式铺满并加白色柔光罩，保证文字可读。
- 注意版权健康度：自己拍的、官方壁纸、可商用素材都行。

现在的 `1.svg` 是一个手绘示例（晴空风景），删掉或覆盖它都可以。
